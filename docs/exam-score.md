# Расчёт итога экзамена: сумма → среднее роли → веса → максимум

Чистый модуль `src/services/exam_score.py` считает предварительный балл команды из отправленных листов оценок. Он не обращается к БД, HTTP и FastAPI, не хранит состояние и не имеет маршрутов: это функция `calculate_exam_score(...)`, которую вызовут будущие задачи (принятие итога #114, ручной итог #116, CSV #121). Пересчёт при смене весов или максимума — это повторный вызов с новыми параметрами.

Формулы соответствуют предложенным решениям Q2 (#95) и Q3 (#96); до подтверждения командой это рабочая версия.

## Вход

| Параметр | Тип | Правило |
|---|---|---|
| `sheets` | `Iterable[SheetScore]` | по одному элементу на отправленный лист: `role` (`teacher` / `manager` / `member`) и `total` — сумма баллов критериев (`int` или `Decimal`) |
| `weights` | `ScoreWeights` | три целых 0…100, сумма ровно 100 (дефолт Exam — 60/30/10) |
| `sheet_max` | `int` / `Decimal` | максимум суммы листа = максимум одного критерия (3 или 5) × число вопросов типа проекта, > 0 |
| `max_score` | `int` / `Decimal` | `max_score` Exam (по умолчанию `25.00`), > 0 |

Один оценщик — один лист. Некорректный вход (сумма < 0 или больше `sheet_max`, `float`, `bool`, NaN/Inf, неизвестная роль, веса не дают 100) вызывает `ExamScoreError` (наследник `ValueError`), а не тихий результат.

## Формула

```
avg_роли = среднее сумм листов роли            (по листам, не по людям-весам)
учитываемые роли = роли с ≥1 листом И весом > 0
B = Σ(w × avg_роли) / Σ(w)                      только по учитываемым ролям
балл = B × max_score / sheet_max
```

- Число оценщиков роли не повышает её вес: роль даёт одно среднее.
- Пустая группа не превращается в ноль, а выпадает из знаменателя. Кворума нет.
- Если учитываемых ролей нет (нет листов или у всех проголосовавших ролей вес 0), результат — «нет расчёта»: `score = None`, `normalized = None`, `no_calculation = True`; деления на ноль нет, ноль не подставляется.
- Вся арифметика точная (`Fraction`), без `float`. Округление — один раз в конце до 2 знаков, половина вверх (`ROUND_HALF_UP`, не банковское). `normalized` и `score` округляются независимо из точного значения; `average` по ролям — только для отображения и в расчёте не участвует.

## Результат `ExamScoreResult`

| Поле | Смысл |
|---|---|
| `score` | итоговый балл экзамена (2 знака) или `None` |
| `normalized` | `B` в шкале листа (2 знака) или `None` |
| `roles` | для каждой роли: `weight`, `sheets_count`, `average` (или `None`), `counted` |
| `used_weight` | сумма весов учитываемых ролей |
| `no_calculation` | признак «нет расчёта» |

## Примеры

Веса 60/30/10, `sheet_max = 25`:

| Листы | `normalized` | `max_score = 25` | `max_score = 100` |
|---|---|---|---|
| teacher 25 и 15, manager 15, member 25 | 19.00 | 19.00 | 76.00 |
| только teacher 20 | 20.00 | 20.00 | 80.00 |
| teacher 20, member 10 | 18.57 | 18.57 | 74.29 |
| нет листов | — | нет расчёта | нет расчёта |

Контрольный: `(20×0.6 + 15×0.3 + 25×0.1) = 19`. Только teacher 20 даёт 20, а не 12 (`20×0.6`).
